# Contact Book 📞

A beginner-friendly Dart console application to manage contacts in memory.

## How to Run

```bash
dart run contact_book/main.dart
```

## Features

- **Add Contacts**: Store name and phone number
- **View All Contacts**: Display all stored contacts
- **Memory Storage**: Data stored in program memory
- **Input Validation**: Ensures name and phone are not empty
- **User-Friendly Menu**: Simple menu-driven interface

## How to Use

1. Choose option 1 to add a new contact
2. Enter the contact name and phone number
3. Choose option 2 to view all contacts
4. Choose option 3 to exit the program

## Learning Objectives

This project covers:
- **Lists**: Using List<Map<String, String>> for data storage
- **Maps**: Creating and accessing key-value pairs
- **Functions**: Creating functions with parameters
- **Control Flow**: Switch statements and loops
- **String Methods**: trim() for input cleaning
- **List Methods**: add() and length property
- **Menu-Driven Programs**: Creating interactive menus

## Key Concepts Demonstrated

1. **Data Structures**: Using List and Map together
2. **Function Parameters**: Passing lists between functions
3. **Switch Statement**: Menu selection logic
4. **Input Validation**: Checking for empty strings
5. **String Manipulation**: Using trim() method
6. **List Operations**: Adding items and getting length
7. **Loop with Index**: Using for loop with counter
