# Simple Calculator 🧮

A beginner-friendly Dart console calculator to learn programming fundamentals.

## How to Run

```bash
dart run simple_calculator/main.dart
```

## Features

- **Basic Operations**: Addition (+), Subtraction (-), Multiplication (*), Division (/)
- **Decimal Support**: Handles both integer and decimal numbers
- **Error Handling**: Prevents division by zero and validates input
- **User-Friendly**: Clear prompts and error messages

## How to Use

1. Enter the first number (can be decimal)
2. Choose an operator (+, -, *, /)
3. Enter the second number
4. View the result
5. Choose to continue or exit

## Learning Objectives

This project covers:
- **Variables and Data Types**: double, String, null safety
- **User Input**: Reading and validating console input
- **Functions**: Creating functions with parameters and return values
- **Control Flow**: if statements, while loops, switch statements
- **Error Handling**: Input validation and division by zero check
- **Lists**: Using lists to validate operators
- **Type Conversion**: Converting String to double

## Key Concepts Demonstrated

1. **Function Parameters**: Passing data between functions
2. **Return Types**: Functions returning nullable types (double?)
3. **Switch Statement**: Alternative to multiple if-else statements
4. **Input Validation**: Ensuring user input is valid before processing
5. **Early Return**: Using return to exit functions early
6. **String Interpolation**: Displaying formatted results
